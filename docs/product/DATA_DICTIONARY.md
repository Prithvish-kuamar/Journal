# Data Dictionary

## Conventions

`R` required, `O` optional, `D` derived, `S` immutable snapshot. Types: uuid, text, enum, decimal, integer, boolean, date, datetime UTC, IANA timezone, ISO4217, json, file-ref. Every material field change has actor/time/audit reference.

| Field family | Type/source | Validation, derivation, snapshot, audit |
|---|---|---|
| Identity/time | uuid, datetime, IANA timezone, tradingDate | UTC source; trading date derived from historical account rollover and never recomputed silently. |
| Account/instrument | Account name/currency/timezone/limits; unresolved account-equity basis; symbol/alias/asset/venue/currencies/tick size/value/multiplier/quantity convention/precision/fee/session hints; execution permission | Live allow-list is XAUUSD, EURUSD, GBPUSD, USDJPY, USDCHF, USDCAD, AUDUSD, NZDUSD per strategy version. Analysis-only symbols cannot execute. Equity-basis selection remains unresolved. |
| Strategy/version | name/number/status/effective date/change summary; `ruleStatus={OWNER-APPROVED,SOURCE-BACKED DRAFT,UNRESOLVED}`, source reference/conflict ID | Published immutable; plan/candidate/trade stores version/definition snapshot; a Source-Backed Draft cannot be presented as owner doctrine. |
| Gate definition/assessment | Gate key/prompt/Yes/No/N-A exception/evidence/order; response; `result`, `diagnosticCompletion`, `lockState`, first/additional failure IDs, timestamps | Historical strategy versions retain 15 keys including mandatory 2R. New versions have 14 mandatory gates; realistic 2R is an optional confluence. No generic N/A: exact rule exception + reason required and cannot bypass mandatory condition. |
| Option library and selections | strategy-versioned category/value/label/colour/order/active/archive/custom metadata; candidate selection label/colour snapshot/note/evidence | Referenced options are archived rather than deleted. Categories include instrument, entry model, timeframe, supply/demand, macro bias, confluence, setup type, optional confluence and target. |
| Expanded execution/outcome | entry timeframe/display snapshot; bias and entry evaluation 0..10; target plan/primary target; close status; exit timestamps; duration; gross/net PnL/costs/method/formula/precision | Timeframe is required before a trade. Closed trades require close status. PnL is calculated only with sufficient versioned metadata or explicitly entered manually with currency and audit. |
| Grade definition/score | Six criterion score-1/score-2 texts; integer score 1..2; total/grade D; confidence/note O | Passed only. C=6/B=7–8/A=9–10/A+=11–12. Calculated grade locks at trade creation; correction stores original/corrected/explanation/audit. |
| Candidate/decision | source/instrument/direction/archetype; lifecycle, disposition, discovered time; no-trade reason/provenance/evidence/confirmation status; missed provenance/estimated R basis | Lifecycle={Preparing,Qualified,Rejected,Expired,Archived}; Disposition={None,Traded,Missed,CorrectNoTrade,Cancelled}. No-trade Pending until end-day/weekly confirm; valid permitted skip changes to Missed. |
| Trade/legs/events | source/status/account/instrument/direction/restrictionBasis; `sessionClassification/sessionPlanVariance/dailyThesisOrdinal/recoveryRevengeIntent`; plan/grade snapshot; legs and management actions/time/price/quantity/reason/cost/evidence | Session is trader-selected Asia/London/New York AM analytics metadata, never a clock-bound rejection. Partial fill starts an executed thesis; no-fill cancellation does not. Third historical thesis is restricted/process violation. Every add has its own leg risk/evidence and planned/unplanned status. |
| Financial values | net P&L; executed risk denominator S; planned-capital denominator S; maximum-risk denominator S; executedR/plannedCapitalR/maximumRiskR D; fees/commission/spread/slippage/reconciliation | Executed R default. Each denominator preserved/displayed; partial fills/exits aggregate net P&L once. Missing source makes relevant R Estimated/Unavailable, never substituted. Currency conversion only for currency totals. |
| Evidence/review/mistake | file metadata/association; review questions/grades/classification/lesson; code/observed impact/counterfactual estimate/basis | Secure validation; capture/upload provenance; complete review locks; 17 code taxonomy with historic snapshots. |
| Views/import/weekly/audit | query/layout; mapping/job/row result; period/filter/metric/objective snapshot; actor/entity/action/before-after/reason | Owner-scoped; idempotent import; publish/completion/audit append-only. |

## Core enums

`CandidateLifecycle={Preparing,Qualified,Rejected,Expired,Archived}`; `CandidateDisposition={None,Traded,Missed,CorrectNoTrade,Cancelled}`; `GateResult={InProgress,Passed,Rejected}`; `DiagnosticCompletion={Partial,Complete}`; `GateLockState={Draft,Locked}`; `NoTradeConfirmation={Pending,Confirmed}`; `RestrictionBasis={Rejected,C,RestrictedB}`; `TradeStatus={Planned,Active,Closed,Archived,Corrected}`. A display label “Rejected setup taken anyway” is `RestrictedSetupTakenAnyway` with `RestrictionBasis=Rejected`.
